# Учебный интернет-магазин

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.
В качестве темы выбран учебный интернет-магазин канцтоваров с каталогом,
карточками товаров, сравнением, отзывами, FAQ и формой заявки.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров с фильтрами;
- `product-pen.html` — подробная карточка товара;
- `product-pencil.html` — подробная карточка товара;
- `product-ruler.html` — подробная карточка товара;
- `product-ella.html` — подробная карточка товара;
- `comparison.html` — таблица сравнения товаров;
- `reviews.html` — страница отзывов;
- `faq.html` — страница часто задаваемых вопросов;
- `contacts.html` — контактная страница;
- `css/style.css` — файл стилей;
- `js/main.js` — логика модального окна и проверки формы;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML5;
- CSS3;
- JavaScript;
- Git;
- GitHub.

## Реализованные самостоятельные доработки

- собственная зеленая визуальная концепция проекта;
- расширенный каталог товаров;
- дополнительные страницы: отзывы и FAQ;
- отдельная подробная страница для каждого товара;
- таблица характеристик на каждой странице товара;
- кнопка заказа с модальным окном на каждой странице товара;
- блок отзывов на главной странице и отдельная страница отзывов;
- блок часто задаваемых вопросов на главной странице и отдельная FAQ-страница;
- расширенная таблица сравнения товаров;
- модальное окно для оформления заявки;
- sticky-фильтр каталога на широком экране;
- несколько вариантов карточек через БЭМ-модификаторы;
- состояния кнопок, карточек и полей формы;
- улучшенная доступность формы через `label`, `required`, `autocomplete`, `aria-invalid`;
- аккуратная работа с изображениями товаров и логотипом.

## Текущий статус

Проект собран как многостраничный учебный сайт и готов к проверке.
